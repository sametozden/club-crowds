# Club Crowds project context

- This is an experimental GitHub project refactoring the PHP/jQuery application in `old-project/`, which must remain untracked.
- The new frontend uses React and the same chart library as the original (amCharts). Compare clubs and leagues by historical attendance and occupancy.
- `old-project/bot-new.php` is the reference for the Transfermarkt attendance importer.
- Do not connect to a local database. Produce SQL suitable for importing on the server.
- Do not implement social chart sharing. Use the existing club and league images from `old-project/images` alongside their names and in charts.
- Project name: Club Crowds. Site title: ClubCrowds: Football Attendance History & Comparisons.
